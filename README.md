# Young People Survey — предсказание пола по анкетным данным

Исследовательский анализ данных опроса молодёжи (Young People Survey) и
построение моделей бинарной классификации для предсказания пола респондента
по его вкусам, интересам, привычкам и антропометрическим характеристикам.

## Данные

- `responses.csv` — 1010 респондентов, 150 признаков.
- Признаки: музыкальные и медиавкусы, интересы, страхи, привычки, отношения,
  рост, вес, возраст, образование.
- Целевая переменная: `Gender` (female / male).
- В анализ вошли **1004** респондента с известным полом (593 женщины, 411 мужчин).

## Методология

- Задача: бинарная классификация.
- Предобработка в едином `Pipeline`: импутация (медиана/мода), масштабирование
  числовых признаков, one-hot кодирование категориальных. Импутация выполняется
  внутри кросс-валидации — без утечки данных.
- Оценка качества: accuracy, balanced accuracy, 5-фолдовая стратифицированная
  кросс-валидация.
- Анализ связей: корреляция Спирмена (корректна для порядковых шкал 1–5).
- Модели: `DummyClassifier`, логистическая регрессия, дерево решений,
  `Random Forest`, `Extra Trees`, `Gradient Boosting`.

## Результаты

| Модель | Accuracy | Balanced accuracy | CV accuracy |
|---|---|---|---|
| Dummy (most_frequent) | 0.592 | 0.500 | 0.591 |
| Logistic Regression | 0.910 | 0.911 | 0.924 |
| Decision Tree | 0.876 | 0.868 | 0.869 |
| Random Forest | 0.940 | 0.933 | 0.945 |
| Extra Trees | 0.910 | 0.902 | 0.935 |
| **Gradient Boosting** | **0.925** | **0.918** | **0.946** |

**Вывод:** пол надёжно предсказуем по анкетным признакам — ансамбли достигают
~0.95 по кросс-валидации. Наибольший вклад вносят антропометрия (рост, вес) и
интересы (PC, Cars, Reading). Без роста и веса точность снижается до ~0.90–0.91.

## Ограничения

Выборка ограничена молодёжью (преимущественно 15–30 лет). Пропуски восстановлены
статистически. Данные кросс-секционные, выводы носят предсказательный, а не
причинно-следственный характер.
